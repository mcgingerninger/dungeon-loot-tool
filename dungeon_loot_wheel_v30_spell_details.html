⚗ Tag Compatibility System

The generator uses a tag system to prevent nonsensical modifier combinations and promote thematic coherence. Each base item is automatically assigned tags based on its name (fire, cold, storm, shadow, holy, arcane, nature, void, melee, ranged). Modifiers are then drawn from a synergy-weighted pool — modifiers that share a tag with the base item get a bonus weight multiplier, while conflicting tags get suppressed.

Fire items → fire/burn/radiant buffs boosted, cold/storm suppressed
Cold items → cold/frost/storm buffs boosted, fire suppressed
Shadow items → necrotic/stealth/void boosted, holy suppressed
Holy items → radiant/healing/divine boosted, shadow/void suppressed
Arcane items → spell power/teleport/force boosted broadly
Nature items → beast/druid/terrain/healing boosted

Generated item cards show their detected tags and a synergy note explaining what the tag system did for that item.
